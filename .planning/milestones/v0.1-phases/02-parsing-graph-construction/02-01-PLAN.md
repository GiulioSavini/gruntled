<objective>
Extend the pure domain so every fact GRT001 (Phase 3) needs has a home before any parser exists: the config-unknown / module-unknown split for units, modules whose surface is unknown, per-dependency unresolved state, the Dependency options struct (DIAG-03 facts), and diagnostic identity that includes the Unit.

Purpose: The architecture review found that the Phase 1 model forces the parser to drop information (an unknown unit loses its deps/refs; a dynamic config_path has nowhere to go), and each drop is a false-positive or false-negative risk. Fixing the model first means infrastructure never has to invent a workaround.
Output: Updated `internal/domain/repograph` and `internal/domain/diagnostic`, all tests green, arch check green.
</objective>
