         - Setup: corpus := corpusRequire(t), tg := tgVerifyPinned(t), dir := corpusCopy(t, corpus), gr := benchBuildGruntled(t), env := tgEnv(t, tg). Both tools get the SAME env and cmd.Dir = dir. Stdout and stderr go to io.Discard, via a buffer that is only printed on a bad exit.

         - Warm-up: 3 runs of each, untimed, which warms the page cache for both.
         - Sampling: const benchSamples = 21. For i in 0..20, alternate the order (even i: gruntled then terragrunt; odd i: the reverse), so drift and thermal effects are shared. Time each run with time.Now/time.Since around cmd.Run.
         - Every run's exit code must be 0 for both tools. Otherwise t.Fatalf with that run's output: an erroring run must never count as a fast run.
         - Compute min, p25, median, p75 and max for each tool, and ratio = terragrunt median / gruntled median.
         - t.Logf one block of `VALIDATION-BENCH key=value` lines: the machine info, the sample count, the warm-up count, each tool's full sorted sample list in milliseconds with 3 decimals, the stats and the ratio. 04-03 Task 2 transcribes this block.
         - Assert gruntled median < terragrunt median. On failure, t.Errorf with both sample lists. That is a real VALID-06 failure and must never be "fixed" by changing the commands, the sample count, or the comparison.
         - Assert the corpus is untouched: corpusDigest(corpus) is unchanged.

OpenRoot is not needed; call `run([]string{"check", dir}, io.Discard, io.Discard)` inside `for b.Loop()`, where dir is a corpusCopy made before the loop, and check `code == 0` on each iteration (b.Fatalf otherwise). This is the in-process cost, without process start.

The two Benchmark* functions are NOT the VALID-06 comparison, because one is in-process and one is a process. They exist so `go test -bench` users get ns/op numbers. Say so in a comment.
