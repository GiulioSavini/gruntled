<interfaces>
Define in watch.go (the contract everything else uses):
```go
type Changes struct {
	Paths  []string // repo-relative, slash-separated, cleaned, sorted; never absolute, never ".."-prefixed
	Resync bool     // events may have been lost: caller must treat as Invalidate(".")
}
type Watcher interface {
	Ready() <-chan struct{} // buffered(1); signalled when Take would return something
	Take() Changes          // drains pending; empty Changes if nothing
	Close() error           // idempotent; stops goroutines
}
var ErrWatchLimit = errors.New("watch: OS watch limit reached")
var ErrNativeUnavailable = errors.New("watch: native watcher not available on this platform")
```

run.go:
```go
type EventKind int
const (EventIndexing EventKind = iota + 1; EventReady; EventFailed; EventStopped)
type Event struct { Kind EventKind; Report checking.Report; Err error }
type Config struct {
	Watcher  Watcher
	Indexer  Indexer
	Publish  func(Event)           // required; called only from the Run goroutine
	Now      func() time.Time      // default time.Now
	Quiet, MaxWait time.Duration    // defaults DefaultQuiet, DefaultMaxWait
}
func Run(ctx context.Context, cfg Config) error
```
Flow per research Pattern 3/4: Publish(Indexing); `rep, err := Indexer.Index(ctx, nil, false)` -> on error Publish(Failed) and return fmt.Errorf("initial index: %w", err) (ctx cancel during initial index: publish Stopped, return nil); Publish(Ready). Loop: `select` on `ctx.Done()`, `Watcher.Ready()`, and the debounce timer channel. Ready -> `deb.Add(now(), w.Take())`, re-arm one reusable `time.Timer` to `Due()` (Stop+drain correctly, Go 1.23+ timer semantics are fine on go1.27 but still guard with Stop). Timer -> `Flush(now())`; if batch: `Index(ctx, b.Paths, b.Resync)`; on error Publish(Failed) (cancelled ctx -> treat as shutdown); on success, if `len(w.Ready()) > 0` skip Publish (newer changes pending), else Publish(Ready). `defer`/on exit: Publish(Stopped), `Watcher.Close()`. Run is the only goroutine that calls Indexer; document it. Never panic on Indexer errors. Because Take is called in the Run goroutine only, adapters need no extra locking beyond pending.
