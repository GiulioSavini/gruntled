run.go:
```go
type EventKind int
const (EventIndexing EventKind = iota + 1; EventReady; EventFailed; EventStopped)
type Event struct { Kind EventKind; Report checking.Report; Err error }
type Config struct {
	Watcher  Watcher
	Indexer  Indexer
	Publish  func(Event)           // required; called only from the Run goroutine
	Now      func() time.Time      // default time.Now
	Quiet, MaxWait time.Duration    // defaults DefaultQuiet, DefaultMaxWait
}
func Run(ctx context.Context, cfg Config) error
```
Flow per research Pattern 3/4: Publish(Indexing); `rep, err := Indexer.Index(ctx, nil, false)` -> on error Publish(Failed) and return fmt.Errorf("initial index: %w", err) (ctx cancel during initial index: publish Stopped, return nil); Publish(Ready). Loop: `select` on `ctx.Done()`, `Watcher.Ready()`, and the debounce timer channel. Ready -> `ch := w.Take()`; if ch is non-empty (len(Paths)>0 || Resync) `deb.Add(now(), ch)`; re-arm one reusable `time.Timer` to `Due()` (Stop+drain correctly). Timer -> `Flush(now())`; if batch: `Index(ctx, b.Paths, b.Resync)`; on error Publish(Failed) (cancelled ctx -> treat as shutdown), set `unpublished=false`; on success remember `last = rep` and decide publish by whether MORE WORK IS ACTUALLY PENDING, not by channel length alone: skip only if `deb.Due()` reports a non-empty debouncer OR (`len(w.Ready())>0` AND, after a fresh `Take()` into the debouncer, the debouncer is non-empty). Concretely: after Index succeeds, `if len(w.Ready())>0 { if ch := w.Take(); non-empty { deb.Add(now(), ch) } }`, then `if _, pendingWork := deb.Due(); pendingWork { unpublished = true; re-arm timer; skip Publish } else { Publish(Ready{last}); unpublished = false }`. Because Take drains Ready (10-04 invariant), a stale signal ends in an empty Take and falls through to Publish. Also in the Ready branch: after handling, if `unpublished && deb is empty` then Publish(Ready{last}) and clear the flag (covers a spurious Ready arriving after a skip). `defer`/on exit: Publish(Stopped), `Watcher.Close()`. Run is the only goroutine that calls Indexer; document it. Never panic on Indexer errors.
