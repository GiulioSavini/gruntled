    Path (injected Env, no real env reads in tests):
    - linux with XDG_RUNTIME_DIR=/run/user/1000 (absolute) -> /run/user/1000/gruntled/<h>/status
    - linux with relative or empty XDG_RUNTIME_DIR -> falls to UserCacheDir result
    - darwin/windows ignore XDG_RUNTIME_DIR even if set
    - UserCacheDir error -> TempDir fallback
    - h = first 12 hex chars of sha256(root) where root is the EvalSymlinks'd absolute path; a repo and a symlink to it hash identically (t.TempDir + os.Symlink; skip on error); different roots differ; deterministic.
    - Inside(root, path) true when path (after EvalSymlinks of its existing parent) is root or under it (used by cmd to reject --status-file in the repo); false for sibling prefixes (/r/repo vs /r/repo2).
    Write:
    - Write creates dir 0700 (MkdirAll) and file mode 0600 (unix; skip mode asserts on windows via runtime.GOOS); content is exactly the line given.
    - Reader goroutine hammering ReadFile while writer writes 200 alternating well-formed lines never sees a line that is not one of the two, nor missing trailing newline (ENOENT before first write tolerated); no `.status-*` leftovers in dir afterwards.
    - Rename seam: failing N-1 times then succeeding -> Write returns nil after retries; always failing -> returns the error after 5 attempts, tmp removed; sleep seam records 10/20/40/80 ms and tests never really sleep.
    - Unix only: pre-existing dir with mode 0o755 -> Write returns ErrInsecureDir and writes nothing.
  </behavior>
  <action>

Base rule order exactly as in research: linux-only absolute $XDG_RUNTIME_DIR; os.UserCacheDir; os.TempDir. Do NOT lowercase on any OS (document aliasing limitation in the doc comment). Keep the dir short (Phase 11 will put sock and lock beside the status file; no more than ~20 bytes under base).

write.go:
```go
var ErrInsecureDir = errors.New("statusfile: directory is accessible by other users")
type Writer struct {
	Path   string
	Rename func(oldpath, newpath string) error // default os.Rename
	Sleep  func(time.Duration)                  // default time.Sleep
}
func NewWriter(path string) *Writer
func (w *Writer) Write(line string) error   // line includes its trailing newline, written verbatim
```
Write: `MkdirAll(dir, 0o700)`; on non-windows `Stat` the dir and refuse with ErrInsecureDir if `mode.Perm()&0o077 != 0`; `os.CreateTemp(dir, ".status-*")`; write; Close; rename with up to 5 attempts, sleeping 10,20,40,80 ms between attempts (not after the last); on any failure remove tmp. Never log; caller decides (daemon logs once, carries on). The fuzzy mode check uses runtime.GOOS != "windows".
