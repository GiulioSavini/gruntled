    1. TestOracle (DIAG-01 at scale):
       - Generate `synthrepo.Spec{Units: 60, IncludeDepth: 3, DependencyFanout: 3, Seed: 7, Errors: []synthrepo.ErrorKind{BadOutputRef, BadOutputRef, BadOutputRef, BadOutputRef}}` into t.TempDir().

       - Decode the output. The GRT001 subset, projected to {file,line,column,unit}, must equal Manifest.Expected projected the same way (both sorted with the same comparator). Every entry must have severity "error".
       - No non-GRT001 diagnostic may appear.
       - If Render rejects the spec (for example too few references), lower the counts and note the change in the SUMMARY.

    2. TestDeterministicAcrossCheckouts (CLI-03, DIAG-04):
       - Generate the same spec (with errors) into `<tmp>/checkout-a` and `<tmp>/another-name`.
       - For each format (text, json), run each dir twice by path argument. Then `t.Chdir(dir)` and run `check` with no path and `check .`.
       - All stdout byte slices must be equal and all exit codes equal (1).
       - stdout must not contain either temp-dir path, must not contain `__gruntled_repo_root__`, and no JSON `file` or `unit` may start with `/` or contain `:\`.
       - Compare the decoded JSON diagnostic lists for equality. Byte equality already implies an empty Diff. Do NOT import application internals.

    3. TestNoWrites (CLI-05). Follow research Pitfall 11's order: chmod, then snapshot, then run, then snapshot again.
       - Skip when runtime.GOOS == "windows" or os.Geteuid() == 0.
       - Generate the repo, then walk it and chmod every dir to 0o555 and every file to 0o444. Register a t.Cleanup that restores 0o755/0o644 so TempDir removal works.
       - Snapshot every entry (path, size, mode, mtime, sha256 of files). Do not include atime.
       - t.Setenv HOME, XDG_CACHE_HOME and TMPDIR to fresh empty t.TempDir()s.
       - Run check in both formats, then snapshot again.
       - The snapshots must be deep-equal, and the three env dirs must still have zero entries.

    4. TestMutationDiff:
       - Generate a clean repo (Errors empty) and run it: exit 0, zero diagnostics.
       - Then Render with one BadOutputRef, write that tree to a second dir and run it: exit 1.
       - The decoded diagnostic list of the mutated run minus the clean run must equal exactly the Manifest.Expected entry, with nothing removed.
       - Also append an unrelated `output "zz_unrelated" { value = 1 }` to one target module file in the mutated tree and re-run. The diagnostics must be byte-identical: the message must carry no volatile content (research Pitfall 9).

    5. TestHelpMatchesDocs (CLI-02 drift guard):
       - runCLI("check", "-h") gives code 0.
       - Collect every stderr line matching `^  [0-3]  `. There must be exactly 4, and each must appear as an exact line in os.ReadFile("../../docs/cli.md").

    Use only the stdlib plus synthrepo in this file. The binary-links-testsupport rule ignores _test.go deps.
